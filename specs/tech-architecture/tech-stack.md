# Tech Stack

- PHP 7.4+ with WordPress 6.0+
- MySQL/MariaDB custom InnoDB tables through `$wpdb`
- Native WP-Cron, Settings API concepts, AJAX, `WP_List_Table`, and shortcodes
- Vanilla JavaScript and scoped CSS
- Docker Compose development/test environment
- PHPUnit 9, WordPress core test suite, WPCS, and PHPStan for WordPress
